# Contributing

Thank you for your interest in making Pie Bench better!

## Questions and feature ideas

Join our [Discord community](https://discord.gg/R62Udyzum) to ask questions, share feedback, or discuss ideas.
If you'd like to add an engine, a model or a platform, or question a number, we're happy to help you get started.

## LLM usage policy

Pie Bench follows the Rust project's [LLM usage policy](https://forge.rust-lang.org/policies/llm-usage.html). Please review it before using an LLM to prepare a contribution.
